# はじめてのAI教科書（試作版 v0.1）

初心者がスマートフォンで生成AIの基本を学べるWebアプリです。
HTML / CSS / JavaScript のみで動き、ライブラリ・API・ログインは使っていません。

## 使い方

`index.html` をブラウザで開くだけで動きます（サーバー不要）。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | ページの土台。ヘッダーと表示領域だけを持つ |
| `css/style.css` | 見た目（配色・文字サイズ・余白）。色は先頭の `:root` で一括変更 |
| `js/content.js` | **教材データ**（本文・クイズ）。差し替えはこのファイルだけでOK |
| `js/app.js` | 画面の切り替え、クイズの判定、学習状態の保存 |

## 教材の差し替え

現在の第1章の本文とクイズは**仮データ**です（文中に【仮】と表示）。
`js/content.js` の `sections` と `quiz` を正式な文章に置き換え、`draft: false` にすると仮データの注意表示が消えます。
章を増やすときは `chapters` 配列に同じ形のオブジェクトを追加してください。

## 学習状態の保存

学習済みチェックとクイズの回答は、ブラウザの localStorage（キー：`ai-textbook-progress-v1`）に保存されます。
端末・ブラウザごとに別々に保存され、ホーム画面の「学習記録をリセット」で消去できます。
